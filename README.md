# CINEMA v0.2 — расширенный PWA-прототип

## Новое в этой версии
- Живой поиск фильмов и сериалов через TMDB API.
- Постеры из TMDB, если у результата есть постер.
- Настройки TMDB API Read Access Token.
- Подготовка регистрации/входа через Supabase Auth.
- Схема облачной коллекции и Row Level Security в `supabase-schema.sql`.
- Экспорт/импорт коллекции JSON.
- Установка на iPhone через Safari как PWA.

## Запуск
Размести содержимое папки на HTTPS-хостинге. Затем открой адрес в Safari на iPhone → Поделиться → На экран Домой → Добавить.

## Включение реального каталога
1. Создай аккаунт TMDB и получи API Read Access Token: https://www.themoviedb.org/settings/api
2. В CINEMA открой Настройки и вставь токен в поле TMDB.
3. Вернись в Каталог и ищи фильмы/сериалы. Прототип использует поиск TMDB `/search/multi`, язык `ru-RU`.
4. Для отображения постеров используются изображения TMDB.

## Включение регистрации и облачного хранения
1. Создай проект в Supabase: https://supabase.com/
2. Открой SQL Editor и выполни `supabase-schema.sql`.
3. В Project Settings → API скопируй Project URL и anon/public key.
4. В CINEMA → Настройки вставь URL и anon/public key.
5. Зарегистрируйся через приложение. Если включено подтверждение email, подтверди почту.
6. Нажми «Синхронизировать коллекцию».

ВАЖНО:
- Никогда не вставляй `service_role` key в клиентское приложение. Используй только anon/publishable key и RLS.
- Это демонстрационная интеграция. Текущий код отправляет элементы в облако, но ещё не загружает их обратно на новое устройство и не реализует публичные профили/подписки.
- Для настоящей публичной социальной системы нужны отдельные таблицы профилей, отзывов, подписок, блокировок и дополнительные политики безопасности.
- TMDB API key хранится в локальном браузере в этой версии. Для коммерческого запуска стоит перенести запросы через серверную функцию, проверить актуальные условия TMDB и добавить атрибуцию.
- Названия, описания и постеры загружаются из TMDB; этот проект не связан с TMDB и не одобрен им.
- Коллекция без облака хранится в localStorage текущего браузера. Экспортируй резервную копию при необходимости.
